# Эмиттер file_diff: карточка «Изменено файлов» на живых данных

## Чего хочет владелец

Владелец, 2026-11-27, чат интегратора: «по рекомендации» — завести. Задача 323 дала просмотр диффа, но события `file_diff` хаб сегодня не эмитит: карточка диффов в ленте живёт на моках (`src/web/state.js:547`, продюсера в `src/server` нет). Без эмиттера кнопка «Показать дифф» в живой ленте не появляется.

## Что нужно

Хаб по завершении хода агента в сессии с git-деревом считает изменения хода (по `git status --porcelain` + `git diff --numstat` от отметки начала хода, либо по снапшоту индекса на границах хода — выбрать дешёвое) и эмитит в ленту события `file_diff {path, added, removed, step, turn}` — по одному на файл, форма уже зафиксирована потребителем (`state.js`). Правила:

- только сессии с деревом (`use_tree`); projectless — ни событий, ни ошибок;
- untracked-файлы включаются (added = число строк, removed = 0) — заодно закрывается находка приёмки 323 №3 на уровне данных;
- секреты не утекают: в событии только путь и счётчики, патч по-прежнему отдаёт 323-й маршрут через `secret_redact`;
- дедуп по `(path, turn)`: повторный эмит того же файла в ходе заменяет счётчики (потребитель уже умеет, `state.js:551-554`).

Красные тесты: ход с правкой двух файлов → два события с верными счётчиками и turn; ход без правок → ни одного события; untracked-файл → событие с added>0; карточка в UI появляется на живом событии (не моке).

## Границы

Не инвалидация кеша патчей и не деревья подзадач (находки 1–2 приёмки 323 — отдельные задачи). Не тяжёлый `git diff` на каждый чанк: считается один раз на границе хода (машина уже имеет такую границу).
