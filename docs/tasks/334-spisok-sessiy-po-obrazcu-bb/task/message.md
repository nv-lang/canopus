# 334. Список сессий по образцу сайдбара bb: проекты, вложенные дочерние, сворачивание

## Чего хочет владелец

Владелец, 2026-11-28, чат интегратора: «посмотри по исходникам bb, как сделаны вложенные потоки и как они работают, секции, проекты — и сделай также». Список сессий Канопуса должен повторять устройство сайдбара bb: группировка по проектам, дочерние сессии вложены в родительские, группы сворачиваются, статус виден глифом.

## Что нужно

Донор — исходники bb по пину `desktop-v0.50.1` (ревизия a08e116, shallow-клон только для чтения) и разборы docs/research/2026-11-26-bb-threads.md и -bb-architecture.md. Из bb берутся идеи и форма, код не переносится (правило доноров).

В списке сессий Канопуса (src/web):

1. **Группировка по проектам:** сессии одного проекта — секцией с заголовком проекта; сессии без проекта — секция «без проекта». Порядок внутри секции — как сейчас (свежие сверху).
2. **Вложенные дочерние:** дочерняя сессия (наши `…-cNN`) рисуется вложенной строкой под родителем с отступом и линией вложенности, как дети треда в bb; у родителя — счётчик детей; свёрнутая родительская строка показывает статус «худшего» ребёнка (ждёт ответа владельца важнее «работает»).
3. **Сворачивание:** секции проектов и ветки детей сворачиваются; состояние свёртки хранится в localStorage (как прочие настройки вида), переживает перезагрузку.
4. **Статус-глифы:** у каждой строки — глиф состояния (работает / ждёт ответа владельца / ждёт разрешения / молчит / ошибка / завершена) — данные уже есть (waiting_reason из 322); цвет+форма по существующей палитре.
5. Ничего не теряется: поиск/фильтр и переход по ссылке `#s=<id>` работают как прежде; строка сессии остаётся кликабельной.

Красные тесты: сессии двух проектов — две секции; родитель с двумя детьми — вложенные строки и счётчик; свёрнутая секция скрывает строки и переживает перезагрузку; глиф соответствует waiting_reason; старые журналы без детей — плоский вид секции без артефактов.

## Границы

Только проекция и рендер списка (state.js/lists.js/view.js/app.css); протокол, журнал и серверные события не меняются. Drag-and-drop перестановка (у bb есть) — НЕ входит. Секции-закладки bb (ручные секции) — НЕ входят, только группировка по проектам.

## Проверка

Веб-тесты по фикстурам (дерево сессий с детьми и без) + живая проба на копии данных: список из ~75 сессий читается секциями, дети вложены, свёртка переживает перезагрузку.
