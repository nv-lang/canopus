Переименовать во всех проектах владельца (начиная с Канопуса):

1. `docs/` → `docs/` — каталог документации целиком (канон, задачи, исследования, архив).
2. `input/` → `input/` — подкаталог входных материалов в папке каждой задачи.

Реализация по [перечню затронутых мест](../../../research/2026-11-28-task-folder-renaming.md): генераторы путей, читатели, стражи (`check-task-docs.py`, `check-md-links.py` и другие), `.gitignore`, `docs/canon/configuration.md` и конвенция [task-folder.md](../../../canon/task-folder.md), плагин OpenCode, настройка `tasks_dir`, README. Красные проверки: все стражи зелёные после переименования; `check-md-links` не находит битых ссылок; плагин читает задачи из нового пути; живой хаб после обновления main-копии показывает задачи.

1. Стражи проверяют ссылки после переноса.
2. Плагин читает новую и переходную раскладку задач.
3. Миграция сохраняет вложения и приватное состояние.
