# Результат реализации 331

## Маршрут

Владелец, 2026-11-28, текущий чат: «реализация малый путь».
Утверждение spec.md и plan.md передано интегратором по слову владельца «делай по рекомендации».

## Сделано

1. Исполнитель перенёс весь `doc/` в `docs/` своего дерева.
2. Исполнитель перенёс входные подкаталоги задач в `input/`.
3. Исторические документы сохраняют исходные формулировки; ссылки следуют новым путям.
4. Генераторы и читатели используют новые пути.
5. Без явного `tasks_dir` Canopus различает новое и прежнее хранилище.
6. Номера задач учитывают обе раскладки в исторических ветках.
7. Механизм переноса формирует отчёт, резервную копию и проверяет SHA-256.
8. Механизм сохраняет бинарные вложения, HOLD, статусы, имена веток и права файлов.
9. Явный режим `tracked_moved` переносит приватные остатки после обновления отслеживаемых документов через Git.
10. Канон и руководство описывают применение и границы переноса.
