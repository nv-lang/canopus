## Уточнение механизма при применении (2026-11-28)

При проверке следующего проекта мигратор обнаружил запись Git с режимом `160000`.
Такая запись обозначает субмодуль, а не обычный файл.
Мигратор теперь пропускает записи субмодулей при перечислении файлов проекта.
Мигратор не читает содержимое субмодуля.
Проверка охватывает существующий каталог субмодуля и отсутствующую рабочую копию субмодуля.

При проверке diff обнаружена лишняя нормализация относительных Markdown-ссылок вне переноса.
Мигратор теперь сохраняет исходные байты ссылки, если перенос не меняет её источник и назначение.
Проверка сохраняет завершающий `/`, исходное написание пути и окончания строк.

Обе новые проверки воспроизвели дефекты до исправления.
После исправления прошли все 21 тест механизма в `scripts/test-migrate-project-folders.py`.
Описи применения и резервные копии остаются вне Git.
