# hub_test: служебные строки статуса не часть истории сессии

## Чего хочет владелец

Владелец, 2026-11-19, текущая сессия: «продолжай по рекомендации» после сдачи задачи 317;
предложение карточки 318 согласовано ответом «Создать 318».

## Что нужно

`server_live/hub_test` красный на трёх сценариях (`two turns of a chat`, `restart between turns`,
`two pages, one session`) и без правок продуктового кода. Причина: хаб шлёт страницам служебную строку
`session_list_status` (id `list-status-<сессия>`, шаг 0) на каждое изменение статуса, а `Rig @lines_for`
(`src/server/testkit.nv`) исключает из «истории сессии» другие служебные линии (`route_state`,
`machine_state`, `turn_request`, `sessions_ready`), но не эту. Нужно исключить и её.

## Критерии приёмки

- `nova test src/server_live/hub_test.nv --jobs 1 --timeout 900` на Oracle 0.1.6 — зелёный;
- красное до правки доказано на базе: те же три отказа воспроизведены на `576c1113` без правок задачи 317;
- продуктовый код, стражи и живой хаб не меняются.

## Результат и куда он попадает

Правка в `src/server/testkit.nv` (одна строка фильтра), ветка задачи, слияние в `main` — по слову владельца.

## Связи

Задача 317 (класс молчаливых зависаний) — закрыта; этот дефект вне её класса и найден при её приёмке.
