# Реализация 138

Статус: рабочая реализация, ещё не сдана и не установлена.

## Принятый объём

Основа — утверждённые эскизы 08/09 и последнее разделение объёма в `task/message.md`.
Продукт остаётся самостоятельным: ящик OpenCode не используется. Модули транспорта, редьюсера,
истории и backend не изменены; используемые события и registry прежние.

## Сверка с направлением

- Вместо трёх постоянных колонок — две; сведения находятся во вкладке рабочей области.
- Общие статусная строка, полоса «ждут вас» и нижняя строка активности; значения вычисляются из потока.
- Компактные проектные группы, чипы состояния и возраст события; реальное имя агента в строке сессии.
- Сообщения не в пузырях справа: роли подписаны, вертикальная граница; запрос разрешения внутри
  прокручиваемой ленты без модального перекрытия навигации.
- Палитра поверхностей и фиолетовый акцент согласованного эскиза; цвета индикаторов severity сохранены.
  Текст предупреждения/ошибки скорректирован для обязательного контраста 4,5:1 без ослабления тестов.
- Manrope и JetBrains Mono — четыре локальных WOFF2 с лицензиями OFL, latin/cyrillic, переменные веса,
  `font-display: swap`; все четыре подмножества загружаются под исходной CSP.
- На узком экране — список и рабочая область по одному, кнопка возврата, внутренний overflow вкладок и кода.

## Честная граница данных

Сессии не названы задачами. Нет вымышленных номеров, `k/N`, прогноза застревания, свободных замков,
нулевой очереди и команд управления без backend. «Ждут вас» пока означает только фактические запросы
разрешения сессий, не вопросы/обязательства всей команды. «Учёт» показывает только доступные контекст
и стоимость с явной оговоркой об отсутствии `usage.log`. Проверки/отчёты отложены, их фиктивных кнопок нет.
Агент указан у ввода; другого выбирают при создании новой сессии, а не мнимым переключением процесса.

## Доказательства разработки

Новый `console-browser.mjs` использует настоящие модули страницы, управляемый WebSocket и отдельное
подтверждение исходящих событий. Есть задержка до echo создания, две порции ответа с незавершённым ходом,
отмена и поздний кусок; allow/deny; навигация к запросу другой сессии; модель из события/неизвестная;
вкладки/клавиатура/focus, черновики, поиск/закрепление, replay истории, длинные строки/код и 320–1440 px.
Управляемые данные не являются вызовами модели и не записываются в живую БД.

Статику тест подаёт точными байтами через Playwright route, сохраняя CSP: первичная проба реальной HTTP
раздачи обнаружила внешние инъекции защитного ПО машины. Настройки машины не менялись, сторонние
запросы не исключены из итогового assert — в изолированном прогоне их ноль. Исходная регрессия
`app-browser.mjs` отдельно прошла с обычной локальной HTTP-раздачей.

Снимки до/после используют один журнал и viewport: 1440×1000 и 390×844, light/dark. Baseline экспортирован
из принятого `3812748`; рабочие квитанции содержат хеши исходников и признак `sourceDirty`.
Финальный exact-SHA прогон, полный набор/guards, согласование узкого экрана и независимая приёмка
ещё впереди; эти результаты здесь не объявляются полученными.
