# Где действует результат 081

**Организационный статус: HOLD / idle, без закрытия.** По слову владельца,
переданному оркестратором 2026-10-18 в 23:51, работы 081 остановлены;
081 и Nova #100 больше не являются условиями выпуска 0.2.1. Win32-пробы,
Job/restricted token и новые исполнители не запускаются. Для выпуска выбран
новый чистый scratch и закрытие старой вкладки; это решение о выпуске,
а не техническое доказательство durable fence или terminal exit.
Raw, отчёты, refs и рабочие деревья сохраняются без уборки.

Production fence **не поставлен**. README/help/runtime schema пока описывают
прежний код; нового действующего контракта 081 в них нет.

Текущий технический результат — [STOP запуска18](durable-terminal-result-18.md):
исходный RED на свежей базе, реальная Windows counterexample OS scope/write
границы Mutex+intent, actual host contract и раздельные legacy HOLD.
Доказательства — [session-evidence/durable-18/](session-evidence/durable-18).
Это история/указатель задачи, не новая норма или успешная приёмка.

Последующие результаты: [независимая проверка19](durable-terminal-review-18-1.md)
подтвердила только ограниченный пробел, [запуск20](win32-feasibility-result.md)
остановился на ошибке драйвера до Add-Type/Win32 API. Production-интеграция,
полный контракт L/T, host coverage и адресный legacy terminal proof не завершены.
