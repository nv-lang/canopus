# План собственных проб С2-2

Все пути здесь относительно корня дерева. Вызовы только read-only; реальную старую сессию, её сообщения, environment и процессы не запускаю и не изменяю.

1. **Причинная проба кода.** Вход: `core.ts` lifecycle/reassign/end-task; `watch.ts` request→claim→spawn→record/drop; `index.ts` recovery/retry/reconcile; поиск всех вызывающих путей. Ожидается: все переходы, которые могут писать/потреблять watch или создавать старый ход, либо проверяют общий fence, либо дают конкретный контрпример. Метод: ручная сверка call-sites и строк исходников, не grep-count.
2. **Контрактная проба спецификации.** Вход: все 10 REQ, 7 AC, 5 DNC, source trace и границы задачи. Ожидается: каждому требованию соответствует атомарная проверка с наблюдаемым результатом; конкурирующие interleavings/crash и внешние границы имеют один определённый исход или честный UNKNOWN/STOP. Метод: вручную пройти positive/negative сценарии в обе стороны, включая spawn-before-PID-record и новый worker.
3. **Forensic/preservation проба.** Вход: заданный raw manifest (87 копий) и dossier digest, неизменные raw sources, существующие переносимые S1 evidence. Ожидается: количество/байты/хеши совпадут с опубликованной описью; ничего не меняется. Метод: пересчитать все записи и digest, только read-only.
4. **API проба.** Вход: официальный V2 OpenAPI и точная session ID. Ожидается: GET только session metadata и inbox list; безопасно вывести schema/meta keys, counters/IDs/types/status без message bodies/location/секретов; no mutation. Ранее выполненная до этой записи попытка считается предварительной и не выдаётся за пробу с заранее закреплённым ожиданием.

Ни один ожидаемый результат не является фактическим результатом; ниже в отчёте отдельно указаны фактические ответы, команды, ограничения и неизвестное.
