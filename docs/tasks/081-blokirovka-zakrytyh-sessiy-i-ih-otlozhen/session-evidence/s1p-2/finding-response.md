## Производная и точный raw

До правки original `s2-3/before-manifest.json` побайтно равен внешнему freeze
интегратора С2-3 и его manifest entry: 130581 bytes,
SHA `676911c617282bb80dc3c4bd0f6c7b575ccd319a3794dc1046634fb9f9eaa147`.
Логический locator: внешний freeze интегратора С2-3 /
`session-evidence/s2-3/before-manifest.json`. Машинный путь не публикуется.
Новая производная явно не raw early before; fields files/phase/excluded_exact
сохраняются. Точный diff и derivative SHA — `derivative-actual.json`/`derivative.diff`.
Исходный необезличенный root не копируется в публичный diff: он заменён логическим
маркером; полный точный byte diff с root остаётся только внешне при финальном freeze.
Публичный diff точен по структурным полям, но не является raw byte diff.

## Ограничения без ложной полноты

Полные immutable algorithm/sessions/runner и применимые нормы methodology прочитаны;
реестр практики не выдан за доказанную практику. Все 7 direct deliver bodies и
2 дополнительных mailbox consumers проверены. Не перечитывались все несвязанные
UI/плановые функции и payload каждого forensic архива: manifests пересчитаны,
semantics берётся из предметных первоисточников, не из неподтверждённого числа.

Текущие продуктовые AC не исполнены. Windows primitives лишь документальные
кандидаты, не выбранный план. Online API примеры расходятся с actual schema;
административные действия не выведены из них и не выполнялись.
L — авторский проверяемый профиль, не утверждённая владельцем новая граница P1.
В-01/02 остаются вопросами будущих ворот; их safe default не разрешает действия.
Никаких изменений общих настроек, новых агентов, code/tests/admin/live не было.
