## Что нужно

После смены агента строка ленты (agent_switched) показывает реальное усилие (xhigh), а слайдер/кнопка усилия — «None»: событие session_source пишется из job.source с пустым effort (src/server/hub.nv:2420), и на фронте пустой directSource.effort перекрывает options.effort (src/web/view.js:2495), поэтому findIndex даёт -1 и слайдер падает на позицию 0 (view.js:1242). Правка: на фронте считать пустой directSource.effort отсутствующим и брать session.selectedEffort || options.effort; проверить тестами src/web (npm test затронутой части).

## Критерии приёмки

Слайдер и лента показывают одно фактическое усилие после смены агента. Случай пустого effort покрыт тестом.
