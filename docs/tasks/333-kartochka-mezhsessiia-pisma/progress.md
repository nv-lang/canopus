# 333. Ход работы

Маршрут: малый. Интегратор, 2026-11-28, поручение задачи 333 в текущем чате: «Малый маршрут, своё дерево от свежего main».

## Решения

Интегратор, 2026-11-28, письмо в текущий чат: «обе твои трактовки УТВЕРЖДАЮ как интегратор».
Основание интегратора — слово владельца «действуй по рекомендациям».
Владелец подтвердит трактовки постфактум.

- Страница показывает число непросмотренных доставленных писем. Страница сбрасывает число при открытии диалога. Этот счётчик независим от почтового ящика агента. Сервер не передаёт странице флаг `taken`. Точный серверный счётчик требует отдельного контракта.
- Страница отмечает срочность только после события `turn_resume` из задачи 324. Проекция привязывает событие к последнему письму того же хода. Срочное письмо без подтверждённого прерывания не получает пометку.

## Изменения

Проекция сохраняет вопрос `qN` и ответ на `qN` в карточке письма.
Проекция восстанавливает идентичность отправителя из доступного `turn_request` при однозначном совпадении отправителя и текста.
Номер запроса не используется как ID хода журнала.
Для старых журналов действует разбор прежнего префикса.
Если ID отсутствует, страница использует единственное совпадение имени среди известных сессий.
Если отправитель неизвестен, страница показывает имя без ссылки.

Ссылка открывает диалог отправителя.
Короткое письмо раскрыто сразу.
Письмо длиннее 600 символов или восьми строк свёрнуто.
Страница сохраняет счётчик доставленных в подключённую страницу писем в локальном хранилище браузера.
Повтор события не увеличивает счётчик.
Загрузка истории не увеличивает счётчик.
Протокол писем и формат журнала не изменены.
