# Машина: Выбор родного режима семьи

- machine: FamilyApprovalPolicy
- revision: 1
- alula_version: 0.28

Хаб проверяет точный идентификатор по ACP/каталогу, не по позиции или названию семьи. Запрошенный выбор сохраняется отдельно от подтверждённого, в том числе для честного показа ошибки. Таблица разрешает применение только предложенного режима. Протокольный адаптер отдельно ждёт успешный set с точным значением до prompt. Родной режим не меняет WorkModePolicy.
