## Критерии приёмки

1. Визуальное направление и существенные решения согласованы непосредственно с владельцем в этой вкладке и записаны с датой/источником; интеграторские предположения не выданы за его выбор. Сначала наглядное согласование, затем реализация.
2. Новый экран заметно отличается от установленной 130 по согласованным с владельцем признакам, а не только отступами/радиусами. Есть сравнение до/после и конкретная сверка результата с принятым направлением.
3. Работающие чатовые функции, 131 model slot и 132 agent registry/134 handlers сохранены, history/backend не меняются ради дизайна. Нет fake controls, утечек, unsafe HTML или ослабления CSP.
4. Реальные desktop/узкий light/dark screenshots и browser actions; минимум три различающие пробы, включая создание/отправку/отмену или разрешение/границы layout. Полный затронутый набор через очередь, guards и signed commit с точным SHA; прежние тесты не ослаблены.
5. Независимая приёмка и линейный exact-SHA candidate CI/precheck/merge, после чего отдельное разрешение на установку. Одобрение визуального эскиза не заменяет итоговые функциональные проверки.
