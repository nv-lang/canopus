с датой и источником. Это **направление, а не утверждение финального дизайна**: конкретная композиция,
размеры и детали согласовываются дальше в разговоре с владельцем и дописываются сюда тем же порядком
(слова владельца дословно, дата, источник).

Три прежних эскиза (01 «Тёплая мастерская», 02 «Графитовый пульт», 03 «Светлая студия») — отклонены

Доводы, на которые владелец отвечал выбором (разбор в чате, не слова владельца):

2. Они рисуют чат-приложение (клон Claude.ai / Codex), а не пульт команды: нет обзора «кто ждёт ответа»,

3. Низкая плотность: много пустоты при работе «на весь день».

## Границы направления

- Композиция: обзор команды — первичный экран; разговор — панель, открываемая из обзора, а не единственное
  содержимое экрана.
- Оформление: строгое, утилитарное, плотное; тёмная тема — основная для согласования, светлая обязательна
  по заданию, но выводится из той же системы.
- Всё остальное из задания неизменно: функции сохраняются, scope 135/136/137 не трогаем, живой пульт не
  меняем без отдельного слова владельца.
