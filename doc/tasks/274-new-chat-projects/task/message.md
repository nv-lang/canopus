Заказчик: владелец CrewHarness.
Репозиторий: nv-lang/canopus. Дата задания: 2026-10-31.
Источник: чат оркестратора; слова владельца — в разделе ниже.
Ветка: нет на этапе Подготовки задачи; назначается только при запуске исполнения.

## Чего хочет владелец

- «при начале нового чата, показываешь окно сообщения посередине экрана + выбор папки (проекта), сам выбор папки должен имитировать Проводник в Линуксе или что-то такое с цветными иконками.» (владелец, 2026-10-31, чат оркестратора CrewHarness, обсуждение интерфейса чатов, O-15).
- «эти задачи делай супер быстро, показывай мне на сдачу на стестовом сервере» (владелец, 2026-10-31, чат оркестратора CrewHarness, обсуждение интерфейса чатов; адрес сдачи: http://127.0.0.1:8100/).
- «через opencode запускай» (владелец, 2026-10-31, чат оркестратора CrewHarness, обсуждение интерфейса чатов).

## Что нужно

1. Новый чат: поле сообщения по центру, над ним выбранный проект и контекст рабочей папки. После первого сообщения — обычная лента; введённый текст и вложения сохраняются.
2. Меню проектов: поиск, существующие проекты, выбор новой папки, «Работать без проекта».
3. Сделать файловое окно в духе Linux: цветные папки, избранные места, хлебные крошки, назад/вверх, поиск текущей папки, одиночный выбор, двойной клик/Enter для входа, подтверждение и отмена.
4. Использовать реальный API выбора/обзора папок; демонстрационные каталоги прототипа не выдавать за файловую систему. Не включать пути машины и частные названия в примеры и репозиторий.

## Критерии приёмки

AC-1. Новый чат центрирован; выбор проекта и возврат из окна папок не теряют черновик, голосовой ввод и выбор агента.

AC-2. Навигация, поиск, выбор корня и отмена работают с каталогами тестового проекта; выбранная папка совпадает с переданной серверу.

AC-3. Окно и управление помещаются на 360 и 1024 px; фокус не уходит за модальный диалог, Escape закрывает его.
