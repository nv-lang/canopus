1. В Crew есть runtime dialog, но нет настоящего хозяина `task_runner`, typed completion
   сессий/проверок и истории доказательств раннера. Изменить только route-поля — значит
   дублировать или обойти сценарий Алулы. Требуется интеграция lifecycle, не локальный фикс.
2. Не согласованы owner-event с сохраняемыми коррелированными решениями и формат
   артефактов для `SessionLaunchResult`/`ReviewResult`; строка агента не разрешение владельца.

   зелёные 587 тестов не включают собственные тесты этой машины. Поставка внешнего
   checkout/комплекта Методики для установленного продукта ещё не выбрана.
