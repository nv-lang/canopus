# Квалификация С2-2 и дополнительные ошибки evidence

Источник: полное чтение отчёта/contract-audit/requirement-map/read-map и собственные
поздние read-only команды интегратора, 2026-10-18. Не ранний before и не GO.

## Маршрут

С2-2 предъявила пять существенных замечаний, две поверхностные пометки и пять проб.
Отрицательные замечания S1–S5 пригодны для предметной авторской правки; положительной
приёмки нет. Ранние before содержат лишь 9/14 путей, поздний reconciliation — 26,
а не всё дерево. Позднее измерение не восстанавливает early before. Методическое
чтение длинных строк также имеет раскрытые ограничения. Чистой проверкой заход не
считается. История С2-1/С2-2, серия 0 и потолок 4 остаются; следующая проверка — 3.

S1/S4 требуют измеримых исходов close/start/crash, а не выбора всей архитектуры в spec.
S2/S3 требуют честной границы подконтрольных операций/внешнего API/OS. Нельзя тихо
ослабить цель владельца до одного interrupt или разрешить #94 с неизвестными угрозами:
спорная граница оформляется предложением/вопросом с безопасным HOLD до решения.
S5 — атомарное покрытие, вопросы, действующие docs/CI/тестовые поверхности. Две
пометки M1/M2 перекрываются с S1/S4/S5; доказательственные обязанности не становятся
поверхностными из-за такого заголовка. Не терять их при правке и не удваивать смысл.

## Ошибка identity в forensic-verification.json

Строки 14–67 перечисляют шесть run1 IDs нового worker, одну отсутствующую старую
запись и run2 старой сессии. Для первых шести уже стоит `session_match: false`.
Называть этот смешанный список перечнем watches старой сессии неверно.

Собственная адресная сверка интегратора подтвердила:

- `1792260030319-ie8bde`, `1792260067690-t7zy8c`, `1792260097037-xabdxk`,
  `1792260111664-pr9xpd`, `1792260127576-aag98z`, `1792260159699-hre9bp` принадлежат
  replacement `ses_mvcoxay3pjag7acd92`, **не** old `ses_mvawdsam690xeqwzpp`.
- На момент собственной поздней проверки по точному old session обнаружены шесть
  done records: `1792187099073-itfcuj`, `1792190755214-ea51zn`,
  `1792194428378-i8kvs7`, `1792209979806-8xdhpt`, `1792224406828-s0k28y`,
  `1792264172390-3ns1ev`. Non-done/request/claim по old ID не найдено.
- В исходном old-watch-inventory были также `1792179830027-y3slcn` и
  `1792183468927-mmg9gt`; в текущем каталоге этих records уже нет, но их raw-копии
  сохранены и входят в проверенные 87. Причина исчезновения здесь не установлена.

Снимки разных моментов и разные множества не сливать в одно. Счётчик сам по себе
не доказывает правильную принадлежность. Любые будущие адресные действия сначала
сопоставляют текущую immutable identity/owner; run1 replacement не является целью
сдерживания old session. Административных mutations по смешанному списку не было.

## Ошибка expected digest

`forensic-verification.json:13` содержит 63-символьный expected SHA, не равный его же
64-символьному actual. Настоящий digest первичного dossier:
`7a1f831a85caa227d9d3c36c45f6bf34bab144ea29e1080b58607ed8825d9969`.
Копии сохранились; ошибочен expected в отчёте. Старый файл не править. Следующая
сессия закрепляет правильный expected из первичного источника до своей проверки
и публикует отдельный новый результат, не ретроспективный PASS прежней пробы.

## Следующее назначение

Новая С1 правка той же 081: root analysis/spec/trace разрешено изменить с ранним
own whole-tree before/expected, отдельными исходными копиями в новом E, ответом
по каждому замечанию и новыми свидетельствами. Все старые reviews/evidence/raw
immutable. Сам before должен включать **все** existing tracked/hidden/untracked,
а не только git status и выбранные пути. Исполнитель может использовать code/API
чтение и доступные копии, но не запускать старую сессию или реальные admin операции.
Нельзя начинать план/код/тесты/live. Человеко-читаемые новые документы — по-русски;
старые английские карты сохраняются как история с раскрытым происхождением.

До исправления, новой С2 и явных ворот spec остаётся черновиком. Наличие успешного
GET metadata и inbox count=0 — только снимок, не durable fence. Nova #94 HOLD.
