# Задание: Чаты по проектам, закреплённые и сессии без проекта

Заказчик: владелец CrewHarness.
Репозиторий: unitcraft/crew-harness. Дата задания: 2026-10-31.
Источник: чат оркестратора; слова владельца — в разделе ниже.
Ветка: нет на этапе Подготовки задачи; назначается только при запуске исполнения.

## Чего хочет владелец

- «при выборе проекта, ты заметил, что есть выбор "Работать без проекта", тогда нет привязки к ворктри и чат идет просто в сессии, где они и так хранятся обычно .crew-harness\data\sessions» (владелец, 2026-10-31, чат оркестратора CrewHarness, обсуждение интерфейса чатов, O-17).
- «левач часть с сессиями, как на скрине» (владелец, 2026-10-31, чат оркестратора CrewHarness, обсуждение интерфейса чатов, O-18).
- «эти задачи делай супер быстро, показывай мне на сдачу на стестовом сервере» (владелец, 2026-10-31, чат оркестратора CrewHarness, обсуждение интерфейса чатов; адрес сдачи: http://127.0.0.1:8100/).
- «через opencode запускай» (владелец, 2026-10-31, чат оркестратора CrewHarness, обсуждение интерфейса чатов).

## Что нужно

1. Левая панель по образцу: новый чат, закреплённые, проекты с вложенными чатами, сворачивание/«Показать больше», поиск, текущий чат, отдельная группа «Без проекта». Сохранить настоящие статусы и доступные действия сессий.
2. «Работать без проекта» очищает привязку к проекту, ветке и worktree; агент не наследует репозиторий предыдущего чата. Сессия хранится как обычно в <CREW_HOME>/data/sessions/<id>. Хранилище из ADR-0016 не переносить.
3. Новый чат появляется в выбранной группе и выделяется, выбор существующего чата восстанавливает его проект/отсутствие проекта, закрепление и история переживают перезапуск.
4. При отсутствии проекта Подготовка сохраняет черновик постановки в пространстве сессии до явного выбора места задачи; не создавать doc/tasks в случайном репозитории.

## Критерии приёмки

AC-1. Чат без проекта не вызывает ни одного действия с Git, не имеет branch/worktree/project и попадает в «Без проекта».

AC-2. Сообщения и история такого чата восстановлены из обычного каталога сессии; повторное открытие не превращает отсутствие проекта в проект по умолчанию.

AC-3. Поиск, закрепление, группы, выбор чата и show-more работают с реальными данными; приватные папки из скриншотов не попадают в код и примеры.
