## Что нужно

1. Сохранить единое понятие «пресет» вместо двух пользовательских сущностей профилей и наборов; роль процесса остаётся функцией агента, а не моделью.
2. Добавить источник агента двух видов: явная семья/модель/усилие или именованный пул и уровень Light/Medium/Heavy. У каждого уровня — отдельный список явных моделей с флагами активности.
3. Случайно выбирать только активные и доступные элементы нужного уровня. Пустой пул не подменять другой моделью. Сохранить выбранную фактическую модель в ходе сессии.
4. Развести уровень пула, вес задачи и родное усилие модели; сохранить возможность пресета назначать исполнителя роли с учётом веса задачи. Решить момент выбора модели по Q-01 эпика; подготовить переход старых настроек без их потери.

## Критерии приёмки

AC-1. При прямом выборе модель/усилие сохраняются точно; при выборе пула разрешаются только включённые элементы указанного уровня.

AC-2. Пустой уровень даёт понятную ошибку; тест со своим генератором случайности воспроизводим; выбранная модель видна в журнале.

AC-3. Пресеты, роли и настройки существующей сессии читаются после перехода; уровни пула не превращаются в усилия Low/High по совпадению названий.
