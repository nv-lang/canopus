## Контракт 270/272

- `GET /api/presets` сохраняет `active`, `roles`, `presets`; каждый пресет дополнен `pools`.
- Прямой источник: `{family,model,effort}`. Пул: `{pool,level}`, где `level` — `light|medium|heavy`.
- `pools`: `{name:{level:[{family,model,effort,active}]}}`; пропущенный `active` означает `true`.
- Сигнал `session_source`, `input` — источник; источник хранится в журнале сессии.
- Выбор закреплён для чата; перед ходом проверяется активность элемента. Выключенный элемент заменяется активным того же уровня. Позднее слово владельца, 2026-11-01, чат интегратора, письмо 00:36, заменяет прежний выбор на каждом ходе. Во время хода источник менять запрещено.
- Уровень пула не является родным усилием и не преобразуется из веса задачи неявно.
- Доступность определяется точной парой семьи и модели из настоящего каталога ACP, а не наличием команды семьи.
- Настройки подтверждений каждой семьи остаются обязанностью 272; источник не меняет их.
