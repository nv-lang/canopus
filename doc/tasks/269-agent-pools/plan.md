## Контракт 270/272

- `GET /api/presets` сохраняет `active`, `roles`, `presets`; каждый пресет дополнен `pools`.
- Прямой источник: `{family,model,effort}`. Пул: `{pool,level}`, где `level` — `light|medium|heavy`.
- `pools`: `{name:{level:[{family,model,effort,active}]}}`; пропущенный `active` означает `true`.
- Сигнал `session_source`, `input` — источник; источник хранится в журнале сессии.
- Выбор закреплён для чата; перед ходом проверяется активность элемента. Выключенный элемент заменяется активным того же уровня. Позднее слово владельца, 2026-11-01, чат интегратора, письмо 00:36, заменяет прежний выбор на каждом ходе. Во время хода источник менять запрещено.
- Уровень пула не является родным усилием и не преобразуется из веса задачи неявно.
- Доступность определяется точной парой семьи и модели из настоящего каталога ACP, а не наличием команды семьи.
- Настройки подтверждений каждой семьи остаются обязанностью 272; источник не меняет их.

## Продолжение, запуск №2

Источник полномочия: интегратор, 2026-11-01, письма 01:48, 02:04, 02:08 и 02:16.
T: runtime ролей 90–150 минут; офлайн-конвертация 90–150 минут. Baseline передан прежним автором, повтор не запускается.

- Старый source роли совместим. Новая форма: `{default:<source>,by_weight:{light?:<source>,medium?:<source>,heavy?:<source>}}`.
- `session_preset {preset,role?,weight?}`: пропущенная роль — `dev`; пустой вес — default, не medium. Неизвестные значения отклоняются; независимую роль запускает серверная операция, не пользовательский input.
- Независимая операция выбирает `dev_accept` и тот же явно заданный вес, исключает фактическую семью исполнителя, подтверждает собственные модель/усилие ACP перед dispatch. Указанный, но недоступный/не независимый источник не подменяется запасной семьёй.
- Старые события `session_preset {preset}` читаются без миграции. Явный выбор пресета сбрасывает предшествующий session_source и закрепление, последующий session_source имеет приоритет.
- Встроенный пресет не перезаписывает явно выбранную семью обычного чата; пользовательский файл с именем `default` разрешается как обычный пресет.
- Конвертер — служебный Python-скрипт, не новый API/MCP; по умолчанию только dry-run. Не читает настройки неявно, не активирует результат, не изменяет источник.
