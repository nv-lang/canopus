# 269. Проверяемый инкремент

Статус: проверяемый инкремент подготовлен для независимой приёмки; не закрытие всего требования владельца. Полный server_live остаётся красным.

## Реализация

- Прямой источник `{family,model,effort}` и источник `{pool,level}`; уровни пула не преобразуются в родное усилие.
- Пресеты дополнены `pools`, прежние роли читаются без переписывания настроек.
- Пул фильтруется по активности, уровню и точной паре семьи/модели из каталога ACP. Пустой уровень — ошибка.
- Подтверждённый выбор сохраняется в журнале и закрепляется между ходами и перезапусками. На очередном ходе проверяется активность.
- `agent_selection` — запрос выбора; `agent_selected` — подтверждённые модель и усилие. До подтверждения source-настроек ACP prompt не отправляется. Отказ не запускает повторный prompt с моделью по умолчанию.
- Источник восстанавливается из журнала; личные настройки и живой экземпляр не изменялись.

## Матрица поведения

| Случай | Поведение реализации | Доказательство |
|---|---|---|
| Активный закреплённый элемент | Сохранить выбор, без новой случайности | Pure- и изолированный интеграционный тесты зелёные |
| Выключение, альтернатива той же семьи | Выбрать активную модель и подтвердить модель/усилие до prompt | Изолированный интеграционный тест зелёный |
| Другая семья до первого хода | Сменить семью без переноса истории | Изолированный интеграционный тест зелёный |
| Другая семья после состоявшегося хода | Явный отказ до отправки; журнал не меняется, сообщение не исполняется | Изолированный интеграционный тест зелёный |
| Пустой уровень | Отказ, без запасной модели | Pure- и изолированный интеграционный тесты зелёные |
| Подтверждённое исчерпание лимита | Автоматический переход не реализован | Не закрыто |
| Неизвестная RPC/transport-ошибка | Не объявлять лимитом, не повторять неопределённый ход | Автоматического retry в инкременте нет |

## Недостающие контракты

1. Структурированное подтверждение `quota_exhausted`: семья, модель, область лимита, срок/условие восстановления и определённость исполнения текущего запроса. Произвольная строка ошибки недостаточна.
2. Безопасный перенос истории в другую семью: подтверждённый импорт полного контекста, не отдельный исполняемый prompt и не молчаливое обрезание `TRANSFER_LIMIT`.
3. Идентификатор и подтверждение dispatch для различения «не отправлен», «начат», «исход неизвестен», чтобы переход не повторил уже исполнявшийся ход.
4. Назначения пулов независимым ролям и маршрутизация по весу задачи не доведены до проверенного runtime-контракта: в этом инкременте применяется явный источник чата и источник роли `dev` пользовательского пресета. Вес не подменяет уровень пула.
5. Автоматическая конвертация прежних `profiles`/`profile_sets` плагина в новый формат не добавлена. Существующие настройки не изменяются; обратная совместимость доказана для старого формата Nova-пресетов, не для полной миграции всех систем настроек.

Общий 8100 не поднимался этим исполнителем; передача интегратору. Push и слияние не выполнялись. Полный fallback при лимитах и весь эпик не объявляются готовыми.
