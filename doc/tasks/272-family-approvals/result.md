# Результат 272

## Реализация

- Отдельная компактная кнопка непосредственно перед микрофоном. Direct показывает фактическое родное значение, pool — «По семьям» с настройками зарегистрированных семей. Имя/id/описание получены из catalog/ACP, без сопоставления по позиции или названию семьи.
- Запрошенные значения `session.approvals` сохраняются независимо от source/model/effort/pool. Черновик передаёт `session_created.approvals`, сохранённая сессия — `session_setting {family,setting:"mode",value:id}`. Используется существующий журнал `setting_chosen`, включая восстановление после restart.
- Requested и подтверждённый `session_model` разделены. Неактивная семья не запускается ради настройки; UI честно пишет, что требуется ACP. Отказ/неизвестный режим не стирают намерение и не включают широкое умолчание при следующем запуске.
- ACP ждёт точный результат set и перед prompt повторно сверяет обязательный родной режим и его доступность. Legacy `session/set_mode` с успешным пустым ответом считается подтверждением согласно ACP. Несовпадающий configOptions, ошибка set, неизвестный/отозванный id блокируют очередь.
- Режимы Build/Plan не выдаются за минимум/максимум прав модели. Подготовка и её server-side запреты не изменены. Настройки семьи наследуются также независимым reviewer, не подменяя его model/effort.
- Политика разрешения применения — `family-approval.alula.md`/JSON; host glue даёт факты каталога, ACP проверяет протокол. Явный пустой список modes отзывает прежнюю доступность каталога.
