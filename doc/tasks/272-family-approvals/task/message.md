## Что нужно

1. Перед микрофоном разместить отдельную компактную кнопку подтверждений: родное значение для конкретной семьи, «По семьям» для пула.
2. Явно настраивать подтверждения каждой семьи; для модели из пула брать настройку её семьи. Родные идентификаторы и возможности получать из каталога/ACP, а не из порядкового номера пункта.
3. Сопоставить общий режим Подготовки и исполнения возможностям адаптеров. OpenCode Build/Plan — агенты с собственными permission; это не минимум/максимум шкалы прав модели. Не обещать ограничения, которые адаптер не обеспечивает.
4. Отделить операции с постановкой от реализации и родных настроек подтверждений. Настройка широких прав не снимает ограничения Подготовки.

## Критерии приёмки

AC-1. Кнопка стоит непосредственно перед микрофоном, показывает реальное выбранное значение; настройки семьи сохраняются после смены модели и выбора пула.

AC-2. Перестановка родных режимов в ответе ACP не меняет смысл сопоставления; нет эвристики «нулевой пункт — Plan, последний — Build».

AC-3. Проверены хотя бы явные поддерживаемые возможности всех настроенных семей; неподдерживаемый режим показан честно, не заменяется более широким молча.
