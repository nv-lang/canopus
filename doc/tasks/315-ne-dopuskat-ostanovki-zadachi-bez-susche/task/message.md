# Задание: Не допускать остановки задачи без существенной причины

Дата: 2026-11-15 21:39

Если агент завершил ход, но задача не выполнена, Канопус должен побуждать его продолжить. Допустимые причины остановки: явная пауза владельца, ожидание необходимого решения или внешняя блокировка. Причину показывать владельцу; исключить бесконечные повторы при неизменной блокировке. Добавить регрессионный тест по случаю задачи 311: агент остановился после объяснения, не завершив проверки.

## Сообщение владельца

добавь задачу, чтобы Канопус не позволял без существенной причины остановится задаче

## Дополнение 2026-11-15 23:21

Завершить реализацию, регрессионный тест случая 311 и проверки по существующей постановке.
