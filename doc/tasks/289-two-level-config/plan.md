## Целевой контракт

Для приложения и плагина независимо: встроенные значения → выбранный глобальный config.json → проектный config.json. Более поздний слой перекрывает предыдущий. Объекты объединяются по ключам, массивы заменяются, false/0/пустые строки и отсутствие значения различаются.

Приложение: ~/.canopus/config.json → <project>/.canopus/config.json.
Плагин: ~/.canopus/plugin/config.json (defaults) → <project>/.canopus/plugin/config.json. Регистрация проектов остаётся глобальной; глобального local и проектных local.json нет. defaults — содержимое глобального уровня, не дополнительный файл или уровень. Секреты остаются отдельно в secrets.json; --config по-прежнему выбирает экземпляр. Не добавлять env/CLI-перекрытия или скрытый кеш поправок.
