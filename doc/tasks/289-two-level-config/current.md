# Результат 289

В основной копии действуют два уровня конфигурации: глобальный → проектный. Публичный контракт — [конфигурация Canopus](../../canon/configuration.md). Проектные правки плагина читаются из основного рабочего дерева сразу; команды выбора профиля пишут проектный config.json без автокоммита. Личные слои не используются.

Явный перенос выполнен для всех шести обнаруженных проектов. Исходные конфиги проверены и сохранены в backups экземпляра; итоговые значения совпали до/после, включая отсутствие ключей, модели, профили, лимиты и режимы ответов. Секреты и состояния других задач не изменялись. Локальные изменения и индекс владельца сохранены.

Профильные проверки конфигурации, переноса и команд зелёные; собраны обе программы, проверены комплект, HTTP/WebSocket и doctor приложения. Сервисы перезапущены с разрешения владельца.

По дополнительному поручению владельца разобраны три сбоя регрессии. Поиск одной задачи проверяет папки её номера, сохраняя проверки коллизий и ссылок. Состояние читается заново. Помощник ожидания проверяет условие после последнего пробуждения таймера: готовый повтор вопроса больше не считается ошибкой. Лимиты ожидания и условия проверок сохранены.

Сценарии инструментов и дочерних задач приложения прошли с исходными проверками при ограниченной параллельности. Полный набор плагина: 183 проверенных файлов; три падения общего прогона перепроверены отдельно по AGENTS.md, п.9. Матрица напоминаний и исправленный тест очереди зелёные.

Покрыт весь актуальный список приложения: 49 PASS, 0 FAIL и 2 штатных пропуска без самостоятельного запуска. Ранее зелёные результаты учтены только для неизменившихся исходников; недостающие сценарии выполнены. Локальные файлы и индекс владельца сохранены. Защита main остаётся включённой.
