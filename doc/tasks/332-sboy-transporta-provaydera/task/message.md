# 332. Сбой транспорта провайдера не останавливает задачу

## Чего хочет владелец

Владелец, 2026-11-28, чат интегратора, со снимком ошибки ACP «Turn error: Query closed before response was received» (провайдер qoder; в тот же день наблюдалась и вторая форма — «Reconnecting 5/5, request timed out» у codex): «включи это в задачи Канопуса, такое надо уметь ловить, модель считает что не может продолжать».

Факт: когда транспорт провайдера исчерпывает переподключения, агент-процесс умирает или молчит, ход остаётся открытым, и задача встаёт — модель в следующем ходе «считает, что не может продолжать». Первый принцип философии ([philosophy.md](../../../canon/philosophy.md)) это прямо запрещает: владелец не должен сам замечать сбой и возобновлять работу.

## Что нужно

Хаб распознаёт сбой транспорта провайдера как типизированный отказ и продолжает задачу сам:

1. **Обнаружение.** Признаки: ошибка ACP-хода вида «Query closed before response was received», исчерпание переподключений транспорта («Reconnecting N/N, request timed out»), закрытие ACP-потока без `end_turn`, выход процесса агента, тишина сверх срока (существующий дедлайн 317). Итог — типизированный код (например `provider_transport_lost`) в журнале, не безымянное молчание.
2. **Закрытие хода.** Открытый ход честно закрывается этим кодом; поздние ответы — `stale` (существующий протокол).
3. **Продолжение.** Канопус сам запускает продолжение с последнего подтверждённого шага: новый ход с handoff-контекстом (механика 324) и служебной вставкой «транспорт провайдера оборвался, продолжи». Число автопродолжений ограничено (настройка, по умолчанию 3, как повтор отправки 310); при исчерпании — пауза с видимой причиной и расходом (норма бюджета философии).
4. **Видимость.** Причина ожидания или остановки показывается в списке сессий (словарь 322 пополняется кодом), событие в ленте.

Красные тесты: агент убит посреди хода — ход закрыт `provider_transport_lost`, продолжение запущено автоматически, задача доезжает до результата; исчерпание лимита продолжений — пауза с причиной; двойного исполнения шага нет (журнал и дедуп).

## Границы

Не чинит сам транспорт провайдера (reconnect-логика — внутри агента). Не перебор обходных путей (отдельная цель философии). Связь: механика 324 (cancel+resume), дедлайн 317, словарь 322, очередь C и daemon 329. Родственная находка у Nova: 2046 (вис pre-exit-drain) — не то же самое, не смешивать.

## Проверка

Команда приёмки — прогон красных тестов карточки плюс живая проба: убить процесс агента в середине хода тестовой сессии и увидеть автоматическое продолжение.
