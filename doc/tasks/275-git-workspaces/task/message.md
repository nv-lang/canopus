## Что нужно

1. Рядом с проектом объединить выбор исходной ветки и рабочего места: папка проекта или отдельная папка (Git worktree). Объяснение worktree: ещё одна рабочая папка, история Git общая, это не новый clone.
2. Подготовка задачи не создаёт и не переключает веток, не создаёт worktree; выбранная для будущего исполнения ветка остаётся предпочтением, а не фактическим состоянием.
3. Сверить проектируемый выбор исходной ветки с ADR-0014: текущая отдельная копия создаётся detached с первым сообщением, ветка задачи — при «В работу». Не заменить этот жизненный цикл обещанием новой ветки сразу при открытии чата без нового решения.
4. Сохранить настройку папки деревьев, переиспользование копии первой задачей, восстановление после рестарта и защиту незавершённых изменений при закрытии. Учитывать отсутствие Git и отсутствие проекта.

## Критерии приёмки

AC-1. При Подготовке нет git switch/worktree add/создания ветки; проект без Git и сессия без проекта не получают фиктивную ветку.

AC-2. Отдельная рабочая папка и исходный commit соответствуют выбору; основная рабочая папка не изменена. Создание ветки задачи проверено отдельно от создания копии.

AC-3. Сессия восстанавливает выбранное место после рестарта; существующие изменённые файлы или коммиты не удаляются без предусмотренного решения.
