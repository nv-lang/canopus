## Поздние уточнения имеют приоритет

- Окончательное название: «Подготовка задачи», коротко «Подготовка».
- Подготовка не создаёт ветку/worktree; выбор ветки в ней скрыт, а не исполняется. Снимок/прототип до этого уточнения может показывать старое состояние.
- Без проекта нет привязки к Git; журнал и сообщения остаются в обычном каталоге сессии по ADR-0016.
- Worktree не clone. По ADR-0014 сессионная копия до оформления задачи может быть detached; подпись интерфейса не должна обещать новую ветку раньше фактического создания.

Для показа владельцу продукт разворачивается на http://127.0.0.1:8100/; файл прототипа не должен подменять там настоящую страницу и backend.
